Design a complete futuristic React web application UI for a gamified productivity platform called **GoalCraft**.

GoalCraft turns real-life goals into a **game-like progression system** where users complete daily quests, earn XP, level up, and progress through milestones toward their goals.

The UI must feel like a **game interface for personal growth**, similar to an RPG progression system.

STYLE:

* Dark futuristic theme
* Deep navy / space purple background
* Neon cyan, blue, and gold highlights
* Glassmorphism cards
* Futuristic headline font + clean readable body font
* Smooth micro animations
* Friendly mascot character that reacts to progress

LAYOUT STRUCTURE:

TOP NAVBAR

* GoalCraft logo
* XP progress bar showing progress toward next level
* Current level indicator
* Mascot icon
* User avatar

LEFT SIDEBAR

Navigation with glowing icons:

Dashboard
Create Goal
Calendar
Milestone Journey
Side Quests
Profile

Sidebar icons animate on hover.

---

PAGE 1 — DASHBOARD (Mission Hub)

Minimal and clean.

Sections:

Welcome Header
"Welcome back, Champion!"

Current Mission Card

* Shows active milestone
* Progress bar
* Percentage completion

Daily Quests

* List of today’s tasks
* Difficulty badges
* XP rewards
* Checkbox interaction

Completing tasks triggers XP animation.

Motivation Panel
Mascot encouragement.

Streak Tracker
Shows current streak.

---

PAGE 2 — CREATE GOAL

This page is where users start a new adventure.

Design a beautiful interactive form.

Fields:

Goal Title
Goal Description
Deadline (calendar picker)
Difficulty preference (optional)

After submission:

Show a loading animation where the AI generates:

* milestones
* daily tasks

Then redirect the user to the **Milestone Journey page**.

The form should feel like **starting a new quest in a game**.

---

PAGE 3 — CALENDAR

A calendar that visualizes the **goal timeline and deadlines**.

Features:

Monthly calendar layout.

Display:

* daily tasks
* completed tasks
* milestone deadlines
* final goal deadline

Important:

The goal deadline should be **visually highlighted** (glowing gold circle).

Days leading up to the deadline should show task indicators.

Completed days glow with success color.

---

PAGE 4 — MILESTONE JOURNEY

Visual progression map showing the user's goal journey.

Design:

A path of milestone nodes.

Example:

Start ●──●──●──● Goal

Completed milestones glow.
Locked milestones appear dim.

Clicking a milestone opens its tasks.

---

PAGE 5 — SIDE QUESTS

Optional bonus tasks that give XP.

Examples:

* Read a book chapter
* Exercise
* Meditation
* Learning challenges

Side quests appear as collectible cards.

---

PAGE 6 — PROFILE

Displays:

User avatar
Current level
Total XP
Achievements
Completed milestones
Statistics

Include badge collection system.

---

ANIMATIONS

Task completion:

* XP popup
* XP bar fills
* mascot reacts

Hover interactions:

* cards lift slightly
* sidebar icons glow

Goal completion:

* celebration animation
* confetti effect

---

TECH STACK

React
TailwindCSS
Framer Motion animations
Component-based architecture
Responsive design

The experience should feel like the user is **progressing through a personal adventure where real-life goals are quests**.
